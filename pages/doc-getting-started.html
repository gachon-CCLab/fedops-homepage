Getting Started.

Prepare your local environment, then choose whether to create a Task, join training, or build an Agent.

A concise guide to the 1.3 workflow. The full working manual is available in Notion.

1. Prepare Agent Studio

Follow Manual 00 for the current Agent Studio setup instructions. Use your FedOps account when working with Tasks and participation. Keep your training data in your local environment.

Open setup instructions — Manual 00 ↗ (opens in a new tab)

2. Choose your workflow

I want to create a Task

Start from a new Web Draft or an existing local model. Prepare the project, create an Initiative Model, and check release readiness before publishing.

Task Owner guide →

I want to join federated learning

Find a published Task in the Registry, request to join, and prepare your approved Task in Agent Studio.

Participant guide →

I want to build and use an Agent

Choose a Base LLM and Tool AI models, select their versions, and validate the Agent before building.

Agent Builder & Serving →

3. Keep code and local data separate

Use the Task’s Data Folder for the files required by its README. Agent Studio provides the data location to the Task. Prepare the Python environment and run the relevant readiness checks before training.
