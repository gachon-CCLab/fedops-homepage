FedOps 1.3 / Document

Build and serve an Agent.

Compose an Agent using a Base LLM, Tool AI models, and a defined execution policy.

A concise guide to the 1.3 workflow. The full working manual is available in Notion.

Compose an Agent Draft

The 1.3 main document describes a Base LLM, one or more Tool AI models, and an Agent Harness that defines tool selection, response behavior, and runtime policy.

Select model versions

Keep the source Federated Task and chosen model version visible for each Tool AI. Validate and test the Draft before building. A completed Agent Build pins those selected versions.

Use locally or connect an application

Use Local Chat and Tool AI execution in Agent Studio, or enable the Serving API to connect an application. Consult Manual 04 for the current runtime settings and API usage.

Read Agent Builder & Serving — Manual 04 ↗ (opens in a new tab)

Improve a component

  1. Select the Federated LLM or Tool AI model that needs improvement.
  2. Return to that model’s source Federated Task and train a new version.
  3. Select the new Global Model in your Agent Draft.
  4. Validate and test it, then build a new Agent revision.
The Agent itself is not trained as one federated model. Improvement happens through the selected component’s source Task.
