The FedOps 1.3 documentation is available on GitHub Pages. This sample announcement demonstrates the proposed News format; it does not declare a production release.

## Start with your role

The manual follows the work users do across FedOps Web and Agent Studio.

- **Getting Started** introduces the Agent Studio environment and launch process.
- **Task Owner** covers creating a Task or importing an existing local model, preparing a Release, and publishing to the Registry.
- **Participant: Join & FL** follows a participation request through local readiness and client execution.
- **Campaign & Server Management** describes training policies and server operation.
- **Agent Builder & Serving** explains selecting model versions, testing an Agent, and using a built Agent.

The developer guide provides the task implementation contracts. The documentation currently includes draft material, so consult the status and notes on the relevant guide.
