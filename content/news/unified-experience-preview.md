This is a sample announcement for the website design review, not a production release announcement.

## One place to start

The proposed homepage introduces FedOps 1.3 and points visitors to the next step: learn the workflow in Docs or open the Console.

The Console preview brings **My Federated Tasks** and **Registry** into the same workspace. Task owners can review their work, while participants can discover published Tasks and inspect participation details.

## A consistent path through the product

Shared navigation, colors, and typography connect the homepage, Console, Docs, Blog, and News. Documentation links stay close to the actions they explain.

The Console uses sample data for this review. Its displayed Tasks and actions illustrate the proposed experience.
