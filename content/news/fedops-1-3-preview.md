FedOps 1.3 brings local model development, federated participation, and Agent delivery into one connected workflow.

![FedOps Agent Studio home development screen](/assets/studio-01.png)

## A workspace for the full journey

Agent Studio connects project preparation, Python environments, local data, and training. Published Tasks and model versions connect that local work to the Registry and shared federated training.

## From a Global Model to an Agent Build

Model versions can become components in an Agent Build. The workflow keeps versions fixed until a new model is selected, tested, and included in a new Agent revision.

## Documentation for each role

The 1.3 working manuals follow Task Owners, participants, Agent Builders, and server operators. The developer guide describes the interfaces used to connect a model and its data.

FedOps 1.3 is presented here as a development preview. This page is an introduction to the documented direction, not a final release announcement or a complete feature compatibility list.
